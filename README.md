📌 Overview

This project is a front-end Netflix-style clone, built using pure HTML + CSS.
It includes a header, hero section, trending movies area, feature sections, FAQ, and footer — designed to look similar to the Netflix homepage.

✨ Features

🔝 Header with logo, language selector, and Sign In button

🎥 Hero section with big headline + email signup form

🔥 Trending Movies card layout with numbered ranking

📱 Multiple feature sections (enjoy on TV, download, kids profile, watch anywhere)

❓ FAQ Section with styled dropdowns

🎨 Clean UI using only HTML & CSS

📁 Project Files

index.html — main page structure

style.css — stylesheet for layout, colors, and UI

Assets/ — all images (logo, background, posters, icons)
